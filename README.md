# Mailchimp for the Sulu Form Builder

Subscribes form submissions to a Mailchimp audience, from a flow in the **Integrations** tab of a form
built with the [Sulu Form Builder](https://sulu.eekes.be/sulu-form-builder-bundle). Every subscription
shows up in the run log of the submission and can be retried from the admin.

## What's inside

- [**Subscribe to an audience**](https://sulu.eekes.be/sulu-form-builder-bundle/mailchimp#using-it): picked from the account, with double opt-in and tags per flow.
- [**Merge fields**](https://sulu.eekes.be/sulu-form-builder-bundle/mailchimp#merge-fields-of-the-audience): first name, last name and phone, plus the merge fields of the chosen audience, loaded from Mailchimp so editors pick them instead of typing tags.
- [**Only with consent**](https://sulu.eekes.be/sulu-form-builder-bundle/mailchimp#only-with-consent): subscribe only visitors who ticked a "Keep me informed" box.
- [**Errors and retries**](https://sulu.eekes.be/sulu-form-builder-bundle/mailchimp#errors-and-retries): subscribers are created or updated by e-mail address, so a retry never creates a duplicate.
